# Mars Guo — Research, Tools & City2049

Personal GitHub Pages entry point for the `marsguo2049` work account.

The homepage organises the portfolio into three connected areas:

1. **Research** — operations-research questions, models and evidence.
2. **Research tools** — workflows for literature review, implementation migration and visual verification.
3. **City2049** — a shared future-city context for interactive OR experiments.

## Project status language

The site intentionally includes both completed work and early ideas, with explicit labels:

- **Published** — a public repository or live project is available.
- **In development** — active work exists, but it is not yet ready for a public repository.
- **Concept** — a direction worth communicating, without claiming an implementation.

This keeps the portfolio useful as a map of both current output and future direction.

## Account boundary

`marsguo2049` is the work account for research, research tools and City2049. Smaller projects inspired by everyday life, playful interactions and creative experiments are presented separately through [Moltpany](https://moltpany.github.io).

## Local preview

Open `index.html` in a browser. No build step is required.

## Publish

GitHub Pages publishes the static site from the repository root on the `main` branch.
